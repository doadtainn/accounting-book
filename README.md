# 記帳本

個人記帳網頁：收支、帳戶、證券、貸款、保險一次管理。資料只存在你自己的電腦（SQLite），用瀏覽器開啟使用，同一個區域網路的手機也能連線。

- 只需要 Python，**不用安裝任何套件**
- 暗色介面，支援繁體中文、English、日本語
- 手機可「加入主畫面」當 App 使用

## 功能

- **記帳**：支出／收入／轉帳，主分類＋子分類，多幣別帳戶與換匯；行事曆點日期就能補登
- **統計**：首頁資產配置、負債配置圓餅圖；支出、收入分類佔比與上月比較；近 6 個月收支趨勢
- **證券戶**：持股、成本、損益、報酬率；一鍵從 Yahoo Finance 更新股價（台股自動顯示中文名稱）
- **信用卡**：目前欠款、每月自動扣款（自動入帳或提醒確認）
- **貸款**：本息拆分、額外還款、還款紀錄核對、與銀行剩餘本金核對
- **保險**：保障型／儲蓄型保單、繳費紀錄、保單價值
- **固定開銷**：自動彙整自動扣款、貸款月付、保費與手動項目，分月繳、年繳統計
- **資產變化**：每天定時更新匯率與股價並記錄淨資產，用圖表看長期變化
- **隱私模式**：一鍵把畫面上的金額變成 `*****`，在外面打開也不怕被看到

## 安裝與啟動（Windows）

1. 安裝 [Python](https://www.python.org/downloads/)（3.12 以上）。安裝時記得勾選 **「Add python.exe to PATH」**。
2. 下載本專案：按頁面上方綠色的 **Code → Download ZIP**，解壓縮到任意資料夾。
   （會用 git 的話：`git clone` 這個儲存庫）
3. 雙擊資料夾裡的 **`start.bat`**。
   - 如果 Windows 跳出安全性警告，按「執行」；或在資料夾開啟命令提示字元，輸入 `python server.py`。
4. 用瀏覽器打開 **http://localhost:5000**

看到黑色視窗顯示「記帳本已啟動」就代表成功。**使用期間不要關掉這個視窗**（可以縮小）。

> macOS／Linux：安裝 Python 3.12 以上後，在專案資料夾執行 `python3 server.py`。

### 開機自動啟動（選用，Windows）

按 `Win + R` 輸入 `shell:startup`，把 `start.bat` 的捷徑放進打開的資料夾。

## 用手機連線（選用）

1. 手機和電腦連同一個 Wi-Fi。
2. 查電腦的 IP（命令提示字元輸入 `ipconfig`，找「IPv4 位址」，例如 `192.168.1.23`）。
3. 手機瀏覽器打開 `http://192.168.1.23:5000`。
4. 第一次啟動時 Windows 防火牆若詢問，請允許「私人網路」。

iPhone 用 Safari 開啟後按「分享 → 加入主畫面」，就能像 App 一樣全螢幕使用。
在外面也想用的話，可以用 [Tailscale](https://tailscale.com/) 這類 VPN 連回家裡的電腦。

## 資料與備份

- 所有資料都在 **`data/ledger.db`**（第一次啟動時自動建立）。
- 備份：把 `data/ledger.db` 複製一份到別的地方即可。
- 換電腦：把 `ledger.db` 放到新電腦的 `data/` 資料夾。
- 更新程式版本時，保留 `data/` 資料夾，其他檔案換成新版即可。

## 安全提醒

**記帳本沒有登入功能。** 只接受本機、區域網路與 Tailscale 的連線，請**不要**用路由器轉發、Tailscale Funnel 或任何方式把 5000 連接埠公開到網際網路，否則任何人都能看到你的資料。

畫面上的「隱私模式」只是遮住金額，不是密碼保護。

## 外部資料來源

- 股價與匯率：[Yahoo Finance](https://finance.yahoo.com/)（非官方公開介面，免金鑰；若服務變更可能失效）
- 台股中文名稱：臺灣證券交易所、證券櫃檯買賣中心 OpenAPI

只有按「更新股價」「更新匯率」或每日自動更新時才會連網查詢，記帳資料不會傳到任何地方。

## 專案結構

| 路徑 | 內容 |
|---|---|
| `server.py` | 後端：資料庫、API、股價與匯率查詢、每日排程（只用 Python 標準函式庫） |
| `static/` | 前端：`index.html`、`js/app.js`（單一檔案，無建置工具）、`css/style.css`、`js/i18n.js`（英日翻譯） |
| `tools/test_server.py` | 開發用：複製資料庫到暫存檔，在 5001 跑測試伺服器 |
| `packaging/` | 實驗性：用 PyInstaller 打包成 Windows 安裝程式（沒有程式碼簽章，可能被 Windows 擋下） |
| `CLAUDE.md` | 開發說明（架構、資料模型、記帳規則、慣例） |
